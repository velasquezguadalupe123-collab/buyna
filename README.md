# Buyna — sales pitch

Interactive sales page for Buyna, a platform that lets Venezuelan stores confirm Pago Móvil and Binance payments without opening the bank app.

Every screen on the page is a demo with sample data: a live owner panel, the payment verification walkthrough, the staff view, the catalog and a pricing calculator.

## Edit

- Text and sections: `index.html`
- Colors and layout: `styles.css` (the palette is at the top)
- Demos and contact details: `app.js` (fill in `CONTACTO` at the top to show WhatsApp and email)

## Publish

The site is served by GitHub Pages from the `main` branch. Any push to `main` updates it in about a minute.
